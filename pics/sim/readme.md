# Simulation Results

This folder contains the simulation videos and animations used to
validate the proposed quadrotor control framework.

The main figures used throughout the documentation are stored in:

```text
pics/
```

while animated simulation results are stored in:

```text
pics/sim/
```

## Contents

- `rrt_planner.gif`
  - RRT* tree expansion and path generation.

- `sim_tracking.gif`
  - Closed-loop trajectory tracking of the quadrotor using
    Feedback Linearization and LPV-MPC.

These animations illustrate the overall performance of the
planning and control architecture presented in this repository.
