# 03. Quadrotor Dynamic Model

## 3.1 Overview

The quadrotor is modeled as a nonlinear 6-DOF rigid-body system
using the Newton–Euler formulation.

The model describes:

- Translational motion
- Rotational motion
- Coupling between translation and rotation
- Gyroscopic effects of the rotating propellers

The inertial frame is used for translational motion, while the
body-fixed frame is used for rotational dynamics and attitude control.

## 3.2 State Vector

The 12-dimensional state vector is defined as

```math
\mathbf{x} =
\begin{bmatrix}
X & Y & Z & u & v & w & \phi & \theta & \psi & p & q & r
\end{bmatrix}^{T}
```

where:

- $(X,Y,Z)$: position in the inertial frame
- $(u,v,w)$: linear velocity in the body frame
- $(\phi,\theta,\psi)$: roll, pitch, and yaw angles
- $(p,q,r)$: body angular velocities

This state vector represents both the translational and rotational
dynamics of the quadrotor.

## 3.3 Translational Dynamics

Using the Newton–Euler formulation, the translational dynamics
expressed in the body frame are

```math
\dot{u} = vr - wq - g\sin\theta
```

```math
\dot{v} = wp - ur + g\cos\theta\sin\phi
```

```math
\dot{w} = uq - vp + g\cos\theta\cos\phi - \frac{U_1}{m}
```

Here:

- $m$: quadrotor mass
- $g$: gravitational acceleration
- $U_1$: total thrust

The equations show the nonlinear coupling between translational
velocity and angular velocity.

## 3.4 Rotational Dynamics

The rotational dynamics are derived from Euler's equations for
rigid-body rotation.

The body angular velocity is defined as

```math
\boldsymbol{\omega} =
\begin{bmatrix}
p \\
q \\
r
\end{bmatrix}
```

and the inertia matrix is

```math
J =
\begin{bmatrix}
I_x & 0 & 0 \\
0 & I_y & 0 \\
0 & 0 & I_z
\end{bmatrix}
```

The control moment vector is

```math
\mathbf{U} =
\begin{bmatrix}
U_2 \\
U_3 \\
U_4
\end{bmatrix}
```

The rotational dynamics are expressed as

```math
I_x\dot{p}
=
(I_y-I_z)qr
+
U_2
-
M_{gyro,x}
```

```math
I_y\dot{q}
=
(I_z-I_x)rp
+
U_3
-
M_{gyro,y}
```

```math
I_z\dot{r}
=
(I_x-I_y)pq
+
U_4
-
M_{gyro,z}
```

where:

- $I_x$, $I_y$, $I_z$: moments of inertia about the body axes
- $U_2$: roll control moment
- $U_3$: pitch control moment
- $U_4$: yaw control moment
- $M_{gyro,x}$, $M_{gyro,y}$, $M_{gyro,z}$: gyroscopic moments

The rotational dynamics contain nonlinear coupling terms such as
$qr$, $rp$, and $pq$.

## 3.5 Rotor Gyroscopic Effect

The total angular momentum generated by the rotating propellers
is defined as

```math
J_{TP}
=
J_r
\left(
\Omega_1
-
\Omega_2
+
\Omega_3
-
\Omega_4
\right)
```

where:

- $J_r$: rotor inertia
- $\Omega_1$, $\Omega_2$, $\Omega_3$, $\Omega_4$: angular velocities of the four rotors

The rotor angular momentum contributes to the gyroscopic moments
in the rotational dynamics.

These effects become more significant during rapid attitude
changes and yaw maneuvers.

## 3.6 Translational Dynamics in the Inertial Frame

For the outer-loop position controller, the translational dynamics
are expressed in the inertial frame.

The acceleration along the $X$ axis is

```math
\ddot{X}
=
\frac{U_1}{m}
\left(
\cos\phi\sin\theta\cos\psi
+
\sin\phi\sin\psi
\right)
```

The acceleration along the $Y$ axis is

```math
\ddot{Y}
=
\frac{U_1}{m}
\left(
\cos\phi\sin\theta\sin\psi
-
\sin\phi\cos\psi
\right)
```

The acceleration along the $Z$ axis is

```math
\ddot{Z}
=
-g
+
\frac{U_1}{m}
\cos\phi\cos\theta
```

These equations show that the translational acceleration depends
directly on the vehicle attitude.

Therefore, accurate attitude tracking is essential for accurate
position tracking.

## 3.7 Kinematic Transformations

The relationship between body-frame velocity and inertial-frame
position is

```math
\begin{bmatrix}
\dot{X} \\
\dot{Y} \\
\dot{Z}
\end{bmatrix}
=
R(\phi,\theta,\psi)
\begin{bmatrix}
u \\
v \\
w
\end{bmatrix}
```

where the body-frame velocity vector is

```math
\mathbf{v}_B =
\begin{bmatrix}
u \\
v \\
w
\end{bmatrix}
```

The relationship between body angular velocity and Euler-angle
rates is

```math
\begin{bmatrix}
p \\
q \\
r
\end{bmatrix}
=
T(\phi,\theta)
\begin{bmatrix}
\dot{\phi} \\
\dot{\theta} \\
\dot{\psi}
\end{bmatrix}
```

For operation near hover, where roll and pitch angles are small,

```math
\dot{\phi} \approx p
```

```math
\dot{\theta} \approx q
```

```math
\dot{\psi} \approx r
```

## 3.8 Control-oriented Model

The resulting Newton–Euler model provides the nonlinear
plant model used for controller development.

The model is subsequently reformulated into:

- An LPV model for the attitude controller
- A feedback-linearized model for the position controller
- A prediction model for MPC
