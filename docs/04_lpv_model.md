# 04. LPV Model

## 4.1 Overview

The attitude controller is formulated using a Linear Parameter-Varying
(LPV) model.

The LPV approach represents the nonlinear attitude dynamics as a
linear state-space model whose system matrices vary with measurable
scheduling parameters.

This provides a compromise between:

- Nonlinear model fidelity
- Linear MPC formulation
- Real-time computational feasibility

## 4.2 Attitude State and Input

The attitude state vector is defined as

```math
\mathbf{x}_a =
\begin{bmatrix}
\phi & \theta & \psi & p & q & r
\end{bmatrix}^{T}
```

where:

- $\phi$: roll angle
- $\theta$: pitch angle
- $\psi$: yaw angle
- $p$: roll angular velocity
- $q$: pitch angular velocity
- $r$: yaw angular velocity

The control input vector is

```math
\mathbf{u}_a =
\begin{bmatrix}
U_2 & U_3 & U_4
\end{bmatrix}^{T}
```

where:

- $U_2$: roll control moment
- $U_3$: pitch control moment
- $U_4$: yaw control moment

The controller tracks the reference Euler angles generated by the
outer-loop position controller:

```math
\mathbf{x}_{a,ref} =
\begin{bmatrix}
\phi_{ref} & \theta_{ref} & \psi_{ref}
\end{bmatrix}^{T}
```

## 4.3 Continuous-time LPV Model

The nonlinear attitude dynamics are represented by the
continuous-time LPV state-space model

```math
\dot{\mathbf{x}}_a(t)
=
A(\boldsymbol{\sigma}(t))
\mathbf{x}_a(t)
+
B(\boldsymbol{\sigma}(t))
\mathbf{u}_a(t)
```

The output equation is

```math
\mathbf{y}_a(t)
=
C\mathbf{x}_a(t)
```

where:

- $A(\boldsymbol{\sigma})$: state matrix
- $B(\boldsymbol{\sigma})$: input matrix
- $C$: output matrix
- $\boldsymbol{\sigma}(t)$: scheduling parameter vector

The matrices $A(\boldsymbol{\sigma})$ and
$B(\boldsymbol{\sigma})$ vary according to the current operating
condition of the quadrotor.

Therefore, instead of using a single fixed linear model, the LPV
model represents the attitude dynamics using a family of linear
models.

## 4.4 Scheduling Parameters

The scheduling parameters are selected from measurable or
estimated variables that affect the attitude dynamics.

A general scheduling vector is defined as

```math
\boldsymbol{\sigma}(t)
=
\begin{bmatrix}
\sigma_1(t) &
\sigma_2(t) &
\cdots &
\sigma_s(t)
\end{bmatrix}^{T}
```

The system matrices therefore become

```math
A(t) = A(\boldsymbol{\sigma}(t))
```

```math
B(t) = B(\boldsymbol{\sigma}(t))
```

As the operating condition changes, the scheduling parameters
change and the corresponding LPV model is updated.

This allows the controller to maintain a better representation of
the nonlinear attitude dynamics over the operating region.

## 4.5 Linearization Around the Operating Trajectory

At each sampling instant, the nonlinear attitude dynamics are
linearized around the current operating trajectory.

The resulting continuous-time linearized model can be written as

```math
\Delta\dot{\mathbf{x}}_a(t)
=
A_k\Delta\mathbf{x}_a(t)
+
B_k\Delta\mathbf{u}_a(t)
```

where:

- $\Delta\mathbf{x}_a(t)$: deviation from the current operating state
- $\Delta\mathbf{u}_a(t)$: deviation from the current operating input
- $A_k$: linearized state matrix at sampling instant $k$
- $B_k$: linearized input matrix at sampling instant $k$

After discretization with sampling time $T_s$, the model becomes

```math
\Delta\mathbf{x}_{a,k+1}
=
A_{d,k}\Delta\mathbf{x}_{a,k}
+
B_{d,k}\Delta\mathbf{u}_{a,k}
```

where $A_{d,k}$ and $B_{d,k}$ are the discrete-time LPV matrices.

This model is used as the prediction model for the subsequent
MPC formulation.

## 4.6 State Augmentation

To reduce steady-state error and obtain smoother control signals,
the controller operates on the incremental control input

```math
\Delta\mathbf{u}_{a,k}
=
\mathbf{u}_{a,k}
-
\mathbf{u}_{a,k-1}
```

The previous control input is included in the augmented state:

```math
\mathbf{x}_{aug,k}
=
\begin{bmatrix}
\Delta\mathbf{x}_{a,k} \\
\mathbf{u}_{a,k-1}
\end{bmatrix}
```

The augmented state-space model is then written as

```math
\mathbf{x}_{aug,k+1}
=
A_{aug,k}\mathbf{x}_{aug,k}
+
B_{aug,k}\Delta\mathbf{u}_{a,k}
```

where

```math
A_{aug,k}
=
\begin{bmatrix}
A_{d,k} & B_{d,k} \\
0 & I
\end{bmatrix}
```

and

```math
B_{aug,k}
=
\begin{bmatrix}
B_{d,k} \\
I
\end{bmatrix}
```

This formulation allows the MPC controller to optimize changes
in the control input rather than directly optimizing the absolute
control input.

## 4.7 Prediction Model

For a prediction horizon $N_p$, the future augmented state
trajectory is recursively generated using the LPV model.

The predicted states can be represented in compact matrix form as

```math
\hat{X}
=
\hat{\mathcal{A}}\mathbf{x}_{aug,k}
+
\hat{\mathcal{B}}\Delta U
```

where the stacked future state vector is

```math
\hat{X}
=
\begin{bmatrix}
\hat{\mathbf{x}}_{aug,k+1} \\
\hat{\mathbf{x}}_{aug,k+2} \\
\vdots \\
\hat{\mathbf{x}}_{aug,k+N_p}
\end{bmatrix}
```

and the stacked control increment vector is

```math
\Delta U
=
\begin{bmatrix}
\Delta\mathbf{u}_{a,k} \\
\Delta\mathbf{u}_{a,k+1} \\
\vdots \\
\Delta\mathbf{u}_{a,k+N_p-1}
\end{bmatrix}
```

The matrices $\hat{\mathcal{A}}$ and
$\hat{\mathcal{B}}$ contain the LPV prediction matrices over
the prediction horizon.

The resulting prediction model provides the basis for the MPC
optimization problem developed in the next section.

## 4.8 Role of the LPV Model in MPC

The LPV model provides a computationally efficient representation
of the nonlinear attitude dynamics.

At each sampling instant:

1. The current attitude and angular velocity are measured or estimated.
2. The scheduling parameters are updated.
3. The corresponding LPV model matrices are obtained.
4. The future attitude trajectory is predicted.
5. The MPC optimization problem determines the optimal control increments.
6. The first control action is applied to the quadrotor.

This process is repeated at every sampling instant using a
receding-horizon strategy.
