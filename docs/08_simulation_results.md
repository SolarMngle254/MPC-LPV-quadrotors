## 8.2 RRT* Path and Trajectory Tracking Result

The resulting RRT* path and the corresponding quadrotor trajectory
are illustrated in the 3D simulation below.

The dashed blue curve represents the reference path generated by
the RRT* planner, while the red curve represents the actual
quadrotor trajectory obtained from the closed-loop control system.

The planner generates a collision-free path through the defined
environment, while the tracking controller drives the quadrotor
toward the reference trajectory.
