# 06. Position Controller

## 6.1 Overview

The position controller forms the outer loop of the cascaded
quadrotor control architecture.

Its purpose is to track the reference position generated by the
trajectory planner and compute:

- Total thrust $U_1$
- Reference roll angle $\phi_{ref}$
- Reference pitch angle $\theta_{ref}$

Feedback Linearization is used to compensate for the nonlinear
translational dynamics.

## 6.2 Position Tracking Error

The position tracking error is defined as

```math
\mathbf{e}_p
=
\begin{bmatrix}
e_x \\
e_y \\
e_z
\end{bmatrix}
=
\begin{bmatrix}
X-X_{ref} \\
Y-Y_{ref} \\
Z-Z_{ref}
\end{bmatrix}
```

where:

- $e_x$: position error along the $X$ axis
- $e_y$: position error along the $Y$ axis
- $e_z$: position error along the $Z$ axis

The error dynamics are obtained by differentiating the position
errors twice:

```math
\ddot{e}_x
=
\ddot{X}
-
\ddot{X}_{ref}
```

```math
\ddot{e}_y
=
\ddot{Y}
-
\ddot{Y}_{ref}
```

```math
\ddot{e}_z
=
\ddot{Z}
-
\ddot{Z}_{ref}
```

## 6.3 Feedback Linearization

A virtual control input is introduced to compensate for the
nonlinear translational dynamics.

For each position axis, the desired virtual acceleration is

```math
v_i
=
\ddot{x}_{ref,i}
-
K_{1,i}\dot{e}_i
-
K_{2,i}e_i
```

where $i \in \{x,y,z\}$.

The virtual acceleration vector is therefore

```math
\mathbf{v}
=
\begin{bmatrix}
v_x \\
v_y \\
v_z
\end{bmatrix}
```

Substituting the feedback-linearizing control law into the
position error dynamics gives

```math
\ddot{e}_i
+
K_{1,i}\dot{e}_i
+
K_{2,i}e_i
=
0
```

The resulting closed-loop error dynamics are linear and decoupled.

The controller gains are selected such that the characteristic
polynomial

```math
s^2 + K_{1,i}s + K_{2,i}
```

is stable.

Therefore, the position tracking error converges asymptotically
toward zero for the nominal model.

## 6.4 Inverse Dynamics

The virtual accelerations

```math
\mathbf{v}
=
\begin{bmatrix}
v_x \\
v_y \\
v_z
\end{bmatrix}
```

are mapped back to the physical quadrotor inputs.

From the vertical translational dynamics,

```math
\ddot{Z}
=
-g
+
\frac{U_1}{m}
\cos\phi\cos\theta
```

the total thrust required to generate the desired vertical
acceleration is

```math
U_1
=
\frac{m(g+v_z)}
{\cos\phi\cos\theta}
```

The horizontal virtual controls determine the required roll and
pitch reference angles.

For the adopted Z-Y-X Euler-angle convention, the horizontal
acceleration equations are

```math
v_x
=
\frac{U_1}{m}
\left(
\cos\phi\sin\theta\cos\psi
+
\sin\phi\sin\psi
\right)
```

```math
v_y
=
\frac{U_1}{m}
\left(
\cos\phi\sin\theta\sin\psi
-
\sin\phi\cos\psi
\right)
```

Therefore, the inverse-dynamics mapping can be summarized as

```math
(v_x,v_y,v_z)
\longrightarrow
(U_1,\phi_{ref},\theta_{ref})
```

The resulting attitude references are then passed to the inner-loop
LPV-MPC controller.

## 6.5 Reference Yaw

The reference yaw angle

```math
\psi_{ref}
```

is provided by the trajectory planner and is treated as an
exogenous input to the position controller.

Thus, the position controller determines the roll and pitch
references required for translational motion, while the trajectory
planner determines the desired heading.

This separates heading control from the planar position control.

## 6.6 Output to the Attitude Controller

The position controller produces the total thrust and the
reference roll and pitch angles:

```math
\mathbf{y}_{pos}
=
\begin{bmatrix}
U_1 \\
\phi_{ref} \\
\theta_{ref}
\end{bmatrix}
```

The trajectory planner additionally provides the reference yaw:

```math
\psi_{ref}
```

Therefore, the complete attitude reference sent to the inner-loop
LPV-MPC controller is

```math
\mathbf{x}_{a,ref}
=
\begin{bmatrix}
\phi_{ref} \\
\theta_{ref} \\
\psi_{ref}
\end{bmatrix}
```

The resulting control structure is

```math
\text{Position Reference}
\longrightarrow
\text{Feedback Linearization}
\longrightarrow
\begin{bmatrix}
U_1 \\
\phi_{ref} \\
\theta_{ref}
\end{bmatrix}
```

while

```math
\psi_{ref}
```

is provided directly by the trajectory planner.

The attitude controller then tracks

```math
\begin{bmatrix}
\phi_{ref} \\
\theta_{ref} \\
\psi_{ref}
\end{bmatrix}
```

using the LPV-MPC controller described in Section 05.
